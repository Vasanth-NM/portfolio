## 🚀 Overview

A personal engineering portfolio showcasing projects, simulations, certifications, and research at the intersection of:
* **3D CAD Parametric Design & FEA Simulation** (Creo, CATIA V5, Fusion 360, ANSYS)
* **Industrial IoT (IIoT) & Digital Twins** (ESP8266, Vibration Telemetry, Random Forest ML, Unity 3D)
* **Smart Manufacturing & Quality Control** (CNC, GD&T, Metrology)

---

## 🎨 Key Features

* **Interactive 3D Viewport:** Live Three.js interactive topological Klein Bottle surface with real-time drag-to-rotate and wireframe toggle.
* **Claymorphic & Glassmorphic UI:** Custom modern glass aesthetic with liquid active navigation pill.
* **Dark / Light Mode:** Fully synchronized theme toggle with persistent preferences.
* **Interactive Project Showcase:** Category filter tabs with detail modals for technical breakdowns.
* **Direct Resume Access:** One-click PDF resume download with automatic cache-busting.
